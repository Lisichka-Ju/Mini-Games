# [Тренировочный сайт](https://lisichka-ju.github.io/Mini-Games/)
Это более структурированная версия [сайта1](https://lisichka-ju.github.io/HTML/)
Здесь представлены мини игры и интересные варианты оформления сайта.

Вообще это сборник моих тренировочных сайтов по шаблонам
Все написано на языках HTML, CSS, JS
На этом сайте есть несколько Картинок с описанием. Это сайты, которые я писала, собранные в один сайт для удобства
___
## 1 Куб
Это модель куба, которую можно вращать на 360 градусов. Управляется стрелками на клавиатуре.
___
## 2 Лес
Это адаптативный сайт с паралакс эффектом. Управление мышкой.
___
## 3 Канвас
Это мини игра. Управление мышкой и нажатием правой кнопки мыши.
___
## 4 Сколл сайт (вниз)
Это адаптивный сайт со скролом. Управление мышкой колёсико мышки.
___
## 5 Скролл сайт (в глубь)
Это адаптивный сайт со скролом. Управление мышкой колёсико мышки. Если нажать на иконку в нижнем левом углу, появится музыка.
___
## 6 Сатурн
Это мини игра. Управление мышкой. Навести мышку на кольца.
